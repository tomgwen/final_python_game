# Stone Age Survival

A turn-based Stone Age survival strategy game developed with Python and pygame.

## Core Gameplay

- Daytime exploration and resource gathering
- Hex-grid movement
- Fog of war
- Crafting and survival management
- Base building and campfire management
- Nighttime defense against wild animals
- Daily events and survival progression

## Technology

- Python 3.11
- pygame
- pytest
